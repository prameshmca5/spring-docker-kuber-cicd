## 📞 Quick Help Reference

### "API calls not showing in logs"
1. Check DevTools is open (F12)
2. Check Console tab is selected
3. Refresh page
4. Make API call
5. Look for blue [INFO] messages

### "Getting status 0 errors"
1. Backend not running or not accessible
2. Check service is up: `kubectl get pods`
3. Check ingress rules: `kubectl get ingress`
4. Check network: `kubectl get service`

### "Getting 404 errors"
1. Wrong endpoint URL
2. Check logs for exact URL
3. Verify backend has route
4. Check Kubernetes routing rules

### "Can't reach backend from frontend"
1. Run `debugHelper.testConnectivity()`
2. Check which endpoints fail
3. Check backend logs: `kubectl logs deployment/backend`
4. Check networking: `kubectl get service`

### "Need to debug Kubernetes"
1. Run `debugHelper.getEnvironmentInfo()`
2. Check cluster info
3. Run `debugHelper.runFullDiagnostics()`
4. Share results with DevOps team
